# Reviews

External or agent reviews of this repo, one file per review: `<UTC timestamp>-<reviewer>.md`.
`scripts/relay/relay.py` writes here when it is used (DRAFTED, not yet run).

Each finding should give:
- area;
- severity (blocker / major / minor / nit);
- evidence (file:line or command output);
- suggested fix;
- a label: Fact or Inference.

Resolved findings get a line in `docs/DECISIONS.md` or `docs/OPEN_ISSUES.md` that links back to the review file.
