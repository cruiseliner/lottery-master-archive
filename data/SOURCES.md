# Data sources

| File | Source | Retrieved by |
|---|---|---|
| `powerball/draws.csv` | NY Open Data `d6yy-54nr` "Lottery Powerball Winning Numbers: Beginning 2010", https://data.ny.gov/resource/d6yy-54nr.json | `lottotool update powerball` |
| `megamillions/draws.csv` | NY Open Data `5xaw-6ayf` "Lottery Mega Millions Winning Numbers: Beginning 2002", https://data.ny.gov/resource/5xaw-6ayf.json | `lottotool update megamillions` |
| `*/missing.csv` | Generated by `lottotool update` from blanks in the data plus `null_rules` in `eras.toml` | `lottotool update` |
| `ingest_log.csv` | One row per newly added draw: Socrata views `rowsUpdatedAt` (upper bound), run start, schedule slot. No historical backfill | `lottotool update` |

* Attribution: New York State Gaming Commission (dataset metadata `attribution`).
* License: the dataset `license` field was **null** when checked on 2026-10-23. No license is
  asserted here beyond what NY publishes.
* NY note: in case of any discrepancy, the official Drawing Unit results prevail.
* Normalisation: zero-padding is removed, Mega Ball comes from its own column, rows are sorted
  ascending, `era_id` is assigned from `eras.toml`, and `source` = `ny:<dataset id>`. Values are
  never filled in or guessed; blanks stay blank and are documented in `missing.csv`.
